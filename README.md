# Cadastro e Login Simples

Este projeto é uma aplicação simples para cadastro e login de usuários, sem autenticação ou validação complexa.

---

## Tecnologias utilizadas

- **Frontend:** React + JavaScript
- **Backend:** Java com Spring Boot utilizando arquitetura MVC
- **Banco de dados:** MySQL  

---

## Funcionalidades

- Cadastro de usuário
- Login simples baseado nos dados cadastrados  
- Armazenamento dos dados no banco MySQL  
- Projeto básico, sem token autenticação e permissão

---

## Como executar

### Backend

1. Configure o banco MySQL e crie a base de dados.  
2. Ajuste as configurações do Spring Boot para conectar ao banco.  
3. Execute a aplicação Spring Boot.

### Frontend

1. No diretório do frontend, instale as dependências e depois execute utilizando o comando:  
   ```bash
    npm install
    npm run dev

Acesse a aplicação pelo endereço mostrado no terminal.

## Observações
Projeto para fins didáticos, sem foco em segurança.

Ideal para entender a integração básica entre React, Spring Boot e MySQL.

Pode ser expandido para incluir autenticação, validação e criptografia.
